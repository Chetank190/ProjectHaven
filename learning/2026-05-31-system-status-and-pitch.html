What it does — successfully

Verified Dual-gateway triage

  • Caseworker (auth'd): notes → itinerary, map, warm-handoff scripts, shift briefing, capacity ticker, case history.
  • Kiosk: voice-first self-serve for an unhoused person.

Verified LLM as a compiler

  • Strict JSON schema + full fallback chain: cloud Gemma → local Nemotron → local Gemma → regex.
  • Never hard-fails with the model or network gone.

Verified Constraint-aware routing

  • 8 pillars over ~2,960 records + 9,255 stops.
  • Masks ID / sobriety / sector / gender / family before the solve; scores distance + occupancy + transit; open-now aware.

Verified Safety before the AI

  • Crisis gate → 988 / 911 + nearest ERs (zero-network).
  • PII scrubbed, prompt-injection blocked, optional NeMo guardrails — all pre-inference.

Verified Dignified voice UX

  • Never cuts you off; eligibility is tap-to-confirm.
  • Type instead on every screen; mute; speaks once; calming centered orb; reservation codes.

Verified Operational smarts

  • Returning-client memory (RAG), weather-aware (extreme cold → warming centres).
  • "Shadow Census" anonymized demand telemetry; live GPU-vs-CPU benchmark per request.

On the Spark Local + GPU

  • Fully on-device inference (Nemotron/Gemma NIM) + Parakeet ASR — audio never leaves the box.
  • cuML KNN in 128 GB unified memory: data + model co-resident, sub-10 ms solve, measured speedup.

Caveat Don't overclaim

  • GPU speedup & local-LLM quality must be measured live on the GX10.
  • Demo data pre-cached; live CKAN/weather is best-effort. Browser STT needs Chrome.

The final interaction — end to end

Idle
Centered orb, "Tap to speak," spoken welcome (mute-aware).
Speak
Tap-to-stop; on-device ASR + browser STT in parallel; natural pauses don't cut you off; "Type instead" always available.
Scrub & screen
PII redaction → injection / guardrails → crisis gate (988/911 + hospitals) — all before the model.
Compile
LLM → NeedsPayload JSON (regex fallback offline); "warm" disambiguated (meal vs clothing vs warming centre).
Eligibility
Up to 3 spoken questions, tap-to-confirm each — a pause never skips one.
Solve
Constraint-masked KNN on GPU (CPU in parallel for the live benchmark) → ranked itinerary.
Deliver
Spoken + on-screen itinerary, walking map, optional printable reservation code.

Hardened in this work cycle
